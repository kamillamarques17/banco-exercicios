Bem-vindos à pasta de atividades práticas da disciplina!

### Como entregar suas atividades (Leia antes de postar):
1. Clique em **Add file** (Adicionar arquivo) > **Create new file** (Criar novo arquivo).
2. No campo do nome do arquivo, digite o **seu nome**, uma **barra (`/`)** e o **nome do arquivo com a extensão** (exemplo: `seu-nome/index.html` ou `seu-nome/exercicio01.html`).
3. Cole o seu código na área de texto abaixo e clique no botão verde **Commit changes...** para salvar.

*(Atenção: não crie arquivos soltos fora da sua pasta!)*

---

### Lista de Exercícios

* **Exercício 01:** Criar uma página HTML básica contendo título principal (`<h1>`), um parágrafo de apresentação (`<p>`) e uma lista não ordenada (`<ul>`) com 3 interesses pessoais.
* **Exercício 02:** Estilizar a página anterior usando CSS (alterar cor de fundo, fonte e centralizar o título).
