### Como entregar suas atividades (Leia antes de postar):
1. Clique em **Add file** (Adicionar arquivo) > **Create new file** (Criar novo arquivo).
2. No campo do nome do arquivo, digite o **seu nome**, uma **barra (`/`)** e o **nome do arquivo com a extensão** (exemplo: `seu-nome/index.html` ou `seu-nome/exercicio01.html`).
3. Cole o seu código na área de texto abaixo e clique no botão verde **Commit changes...** para salvar.

*(Atenção: não crie arquivos soltos fora da sua pasta!)*

* **Exercício 02:** Ideia de Site: Central de Suporte em TI 🖥️🛠️
Problema que resolve:
Muitas pessoas têm dúvidas ou dificuldades com tecnologia (computador travando, internet lenta, impressora que não imprime, etc.).
O site funciona como uma plataforma simples de suporte, onde o usuário encontra soluções rápidas ou pode abrir um chamado.
Funcionalidades dos botões:
Conforme a sua preferencia. Uso a sua criatividade!!

* **Exercício 03:** Crie uma página web com suas receitas favoritas! 
O livro de receitas deve ter uma tabela de conteúdos com links para cada receita abaixo, usando links internos e também imagens das receitas. Uma ideia seria separar por exemplo: uma página de comidas doces e outras salgadas, mas fica a seu critério. Cada receita deve ter uma tabela com os ingredientes, uma lista de detalhes, e uma lista e/ou parágrafos dos passos necessários.
Use CSS para estilizar o livro de receitas, usando uma mistura de seletores simples e cores que você aprendeu.
