# Banco de Exercícios — Lógica e Programação em Python / Html, CSS, JS

Repositório oficial com listas de exercícios, exemplos comentados e atividades práticas para as turmas do Curso Técnico em Informática.

### Como entregar sua atividade:
1. Clique em **Fork** no canto superior direito para copiar este repositório para o seu perfil.
2. Resolva o exercício proposto criando seu arquivo `.py` dentro do seu Fork.
3. Abra um **Pull Request (PR)** com seu nome completo para enviar sua solução para correção.
